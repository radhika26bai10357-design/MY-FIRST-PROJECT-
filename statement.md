Project Statement: Study Planner and Performance Analyzer

Managing academic schedules, study goals, and performance manually can be difficult and often leads to missed study sessions, poor time management, and a lack of awareness about academic progress. Students may struggle to identify weak subjects and determine where they should focus their efforts. There is a need for a simple, organized digital tool that helps students plan their studies, track their academic performance, and analyze their progress effectively.

Scope of the Project

Develop a lightweight command-line interface (CLI) application for study planning and academic performance analysis.

Utilize Python lists and dictionaries to maintain study schedules, subjects, tasks, and performance records during the application runtime.

Provide essential functionalities such as adding study subjects, creating study plans, viewing schedules, recording marks, and analyzing academic performance.

Implement robust error handling to manage invalid user inputs such as incorrect subject selections, invalid marks, and non-numeric entries.

Create a continuous loop interface that keeps the application running until the user chooses to exit.

Target Users

Students who need a simple and organized way to plan their daily study activities and monitor academic progress.

Python Beginners looking for a practical example of lists, dictionaries, loops, conditional statements, functions, and basic CRUD operations.

Time-Conscious Learners who want a quick text-based tool to organize study sessions and identify subjects that require more attention.

High-Level Features

Study Plan Visualization: Displays a clear list of subjects, study tasks, and planned study sessions to provide the user with an immediate overview of their study schedule.

Add Study Task: Allows the user to enter a subject, task description, and study duration and dynamically adds the information to the study plan.

View Study Plan: Displays all planned study activities in an organized and numbered format for easy tracking.

Performance Recording: Enables users to enter marks or scores for different subjects and stores the performance data for analysis.

Performance Analysis: Calculates basic performance indicators such as total marks, average score, percentage, and identifies subjects where improvement is required.

Input Validation: Prevents invalid or empty entries and handles errors gracefully when users enter incorrect data such as non-numeric marks or invalid selections.

Interactive Menu: Provides a user-friendly, text-based navigation system that allows users to access study planning and performance analysis features until they explicitly select the "Exit" option.
